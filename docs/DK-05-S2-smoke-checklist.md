```bash
cd apps/desktop
npx tauri build --debug     # 或 cargo tauri dev 冒烟模式
```
- 留痕：编译成功输出 + 产物路径（`src-tauri/target/debug/aurora-desktop`）。
- 前端 dist 已含 loro wasm data-URL 内联（vite build 验证过 3.0s 绿）。

## 1. IME 组合输入（真实输入法，非合成事件）

1. 打开任一笔记，光标落正文；切换系统中文输入法（拼音）；
2. 连续输入 `nihaoshijie` → 候选窗上屏「你好世界」→ 继续` muyuantong` 上屏；
3. **判据**：组合串不重复不残缺、上屏后 doc 无异常节点；组合期间不出现双重浮层。
4. 留痕：录屏或逐帧截图（组合中 + 上屏后）。

## 2. 滚轮并发输入

1. 打开长文档（导入一篇万字 markdown 或 lab fillLongDoc 思路手工造段）；
2. 滚轮连续滚动中，在可视区继续打字；
3. **判据**：无丢键、无插入位置漂移、滚动位置不跳变。
4. 留痕：录屏 + 文本尾部比对（滚动结束后尾部含滚动中输入的字符）。

## 3. 只读 → 可编辑切换（S1→S2 状态面）

1. 冷启动打开笔记（默认编辑态）→ 侧栏切走再切回；
2. 快速连续切换三条笔记（防抖落库窗口内）；
3. **判据**：无白屏、无内容串写（A 笔记的编辑不落进 B 笔记）、flush 后重开内容一致。
4. 留痕：切回后截图 + 内容比对说明。

## 4. 焦点链（Tauri WebView 焦点语义 ≠ Playwright 合成焦点）

1. 窗口失焦 → 回焦：正文焦点是否保持/可 Tab 恢复；
2. Tab 从侧栏 → 正文 → 工具栏按钮的顺序可达（焦点环可见）；
3. 工具栏按钮 Enter/Space 激活等效点击；
4. **判据**：焦点环始终可见（≥4.5:1 对比）、无焦点黑洞（Tab 死循环/丢失）。
5. 留痕：Tab 序列录屏或焦点高亮截图序列。
