# ADR-007 移动端导航结构（V25 规范对齐裁决）

- 状态: 已接受（C-01 工单 2026-11-16 裁决——代码为准局部修订）
- 范围: apps/mobile 主导航（TabBar/AppBar/抽屉/FAB）
- 关联: ADR-006（tokens 设计基线）;v26_issue清单「V25 导航重构」项（本文落定后由本 ADR 单一说法定案）

## 背景与冲突

V24.1 / V25 移动端规范（已随 V25 大文档退役,1004db7）定义五入口 Inbox / Today /
笔记 / 任务 / 搜索、设置移出主栏、右下 FAB、无中央凸起。而代码（MobileApp.tsx）
实况为 4 Tab（今日/知识库/待办/日历）+搜索已合并 AppBar 右上角（2026-10-28 裁决）
+Agent 在 AppBar+设置在抽屉。两套说法并存,需一次正式裁决。

## 裁决（代码为准,局部修订）

**以代码现状为基础做局部修订**——日历是高频刚需（62KB 实现、CALENDAR-VIVO 系列
12+ 卡迭代、用户已在用）,**不为对齐规范删掉**;规范侧五入口中 Inbox 主入口缺失
（GTD 收集环节真空——捕获直接跳编辑器,无「先收集后处理」缓冲区）为真缺口,补齐。

### 落地形态（单一事实源,后续导航变更以本文为准）

| 位 | 形态 |
|---|---|
| 底部 TabBar | **5 Tab: 今日 / 笔记 / 收集箱（Inbox）/ 任务 / 日历** |
| 搜索 | AppBar 右上角唯一入口 + 硬件键盘 ⌘K / Ctrl+K 等价快捷 |
| Agent | 抽屉「更多」组（非一级导航位） |
| 设置 | 二级:笔记页 AppBar 齿轮 + 抽屉头像行（双入口均二级） |
| 捕获 | 右下 FAB（无中央凸起——现状已合规,锚 `.fab` right/bottom 定位）;键盘弹起自动避让（隐藏） |

### 无障碍与载体规范

- TabBar `role="tablist"`;每 Tab `role="tab"` + `aria-selected` + 图标/文字双载体
- 触摸目标 ≥48×48（现状 56px 合规）;底部安全区 `env(safe-area-inset-bottom)`
- 颜色不作唯一状态标识（文字加粗+aria 双通道——ADR-006 原则承继）

### 收集箱（Inbox）语义（GTD 收集→处理两段）

- **收集**: 捕获面板「存入收集箱」为文字模式主按钮——速记先进收集箱（不跳编辑器,
  保留捕获流的「快」）;localStorage `aurora.inbox`（Rust 侧元数据表落地后迁移
  platform API——同 E21 收藏/回收站前端方案惯例）
- **处理**: 收集箱视图逐条 转笔记 / 转任务（今日）/ 删除;清空兜底
- 捕获面板直出通道（生成笔记/加入今日任务/存为日程）保留——快慢双路径并存

## 与 V25 原规范的差异披露

| V25 原文 | 本裁决 | 理由 |
|---|---|---|
| 五入口含搜索 Tab | 搜索=AppBar+⌘K（无 Tab） | 承继 2026-10-28 已裁决的搜索合并（全局动作不占导航位） |
| 无日历主入口 | 日历保留为第 5 Tab | 高频刚需+大额已实现投入,删除=倒退 |

## 停手边界（v2 候选）

- 导航项用户自定义排序: 不做
- 日历视图: 不删
- 搜索 Tab 化回潮: 不做（除非用户明示裁决）
