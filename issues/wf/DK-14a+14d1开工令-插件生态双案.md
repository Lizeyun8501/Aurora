## 勘察修正（Alpha 2026-10-12 09:35，覆盖预备稿定性）

预备稿称 14a 为"伪成功清除"。**精验后定性修正为 API 卫生**：

- `preload` 的 `new_blob: Vec<u8>` 由**调用方传入**——返回 `Pending` 时 blob 确实已就绪，**状态语义真实，非假报**
- `tokio::time::sleep(1ms)`（hot_update.rs L220-222）是"模拟后台耗时"的**装饰**，无数据伪造
- `simulate_switch_failure`（L175）是显式命名测试钩子，但**挂在生产 pub API 面**
- **hot_update 全模块零生产调用方**（rg 实证：crates/ apps/ 除 hot_update.rs 自身与测试外零命中）——未接线的前置模块
- marketplace.rs 是签名信任链层（Ed25519 sign/verify/is_trusted_by），**无网络分发能力**——"真下载"无处可接

## 案一（DK-14a）：hot_update API 卫生

1. `simulate_switch_failure` + `UpdateJob.switch_should_fail` 注入路径移入 `#[cfg(test)]`（或独立 `test-support` feature）：`confirm_switch` 的失败→`RolledBack` 分支**保留**（状态机语义真实，由测试驱动）
2. `preload` 删除 sleep 1ms 装饰；注释如实化："blob 由调用方就绪后登记，状态流转占位；真实网络分发属 marketplace 未来层"
3. 测试全量保留（钩子移 cfg(test) 后照跑），CI 五门绿
4. **零生产行为变化**（本就无调用方——DoD 用 rg 复核披露）

**DoD**：
- [ ] 生产 API 面无 simulate_* 测试设施
- [ ] sleep 装饰移除，注释如实
- [ ] 测试全绿，行为零变化

## 案二（DK-14d.d1）：Engine Component 化 + 加载路径 + 最小 WIT 合约（并 14b epoch）

**前提实证**（14d 勘察报告 1089183）：wasmtime 36.0.17 在依赖树；`WasmRuntime` 仅 `Engine::default()` 孤挂（L262）无 Config；MSRV 兼容已被 CI 实证；host 绑定零新增依赖。

1. **Config 重构**：`Engine::default()` → `Config::new().wasm_component_model(true)` + **epoch 计时**（`epoch_interruption(true)` + 后台 ticker 线程 + `Store::set_deadline`——**DK-14b 并入本项，一次重构**）+ `ResourceLimiter` 接线（DK-39 经验：Limiter 错误类型走 workspace 显式声明传递依赖）
2. **加载路径**：`Component::new(&engine, wasm_bytes)` 真实加载 API 挂到 `WasmRuntime`（新 pub fn，**不动既有模拟执行段 L331**——那是 d2 的事）
3. **最小 WIT 合约**：单合约文件（plugin host 接口最小面：init/handle_event 两个函数签名 + capability 参数位预留——**14c 前置设计**：合约签名带 capability token 参数，实现可先校验空），host 侧 `wasmtime::component::bindgen!` 生成绑定
4. **验证载荷**：预编译 wasm 载荷 fixture（仓内提交 `.wasm` 或构建脚本产出，勿引 npm/外部构建链——那是 d3）——`Component::new` 成功+合约类型校验过的单测

**DoD**：
- [ ] `Engine` 带 Config（component_model+epoch）构造，epoch deadline 单测（sleep 死循环 wasm 被打断——用 fixture）
- [ ] `Component::new` 加载真实 wasm 成功 + 失败路径返回明确错误
- [ ] WIT 合约文件在库 + bindgen! 编译过 + capability 参数位在签名
- [ ] L331 模拟执行段**零触碰**（d2 边界）
- [ ] CI 五门绿（wasmtime component feature 编译负担已被承担）
