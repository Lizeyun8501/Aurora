# [Alpha→Bravo 派单] DK-编辑器补全：`[[` 触发 wiki 链接标题补全

> 派单方: Alpha ｜ 日期: 2026-10-17 ｜ 前置: 双向链接主体完成（S1+S2+反链面板+rename 跟随）——审阅报告 2.1 尾巴之一
> 领地: desktop（src-tauri commands + 编辑器组件）；core 不动

## 任务 1：数据层——全库标题候选

- `cmd_wiki_link_titles() -> Vec<String>`：全库笔记标题列表（去重排序，trash 排除）
- 数据源：`scan_prefix("note:")` → unseal 读 meta title（**锁定篇 title 在 record 本就明文**——cmd_backlinks_of 同款通路 aab8997 先例）；空标题跳过
- 不含文件夹/SmartFolder（wiki 链接域=笔记标题——rename 跟随同款 kind 纪律）

## 任务 2：编辑器补全浮层

- **触发**：编辑器内输入 `[[` → 浮层弹候选（全量标题，输入即过滤）
- **过滤 v1**：精确子串匹配（大小写不敏感）——模糊匹配（拼音/编辑距离）另批
- **键盘导航**：↑↓ 移动 / Enter 插入 `[[标题]]`（替换 `[[` 及已输入前缀）/ Esc 关闭；点击插入同款
- **插入语义**：目标已有 alias 场景 v1 不做（纯 `[[title]]` 新插入——编辑既有链接不触发补全，诚实边界）
- **纪律**：浮层不阻塞输入（失焦/删除 `[[` 即关）；候选空态显示「无匹配标题」

## 停手条款

- 不做 `[[title|alias]]` 编辑态补全；不做反向（`]]` 后自动收尾光标定位另批）；不做移动端长按触发
- core 不动（标题列表桌面侧聚合）

## 纪律

- desktop 三查+fmt 强制项；键盘焦点管理（浮层开时编辑器输入路由到过滤框/浮层）
- DoD：cargo check（fakepc 面）+CI 全绿+手动路径自查注记（诚实边界照旧）+注记落档直推
