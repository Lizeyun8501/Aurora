## 二、范围（三块，每块 = tauri command + 前端组件）

### 1. 同步状态 UI
- tauri：`cmd_sync_status`（聚合 sync_gate 判定结果 + 最近同步结果/时间）
- 前端：壳层同步状态指示（在线/离线/门控拦截/最近同步），DesktopShell 挂载
- 引擎侧：允许**新增只读查询 fn**（不改既有行为/签名）

### 2. 离线队列可视化
- tauri：`cmd_queue_list`（条目+优先级+状态）/ `cmd_queue_drain`（手动触发补发）
- 前端：队列视图（pending/失败项列表 + 重试按钮）——DK-41 桥接后 drain 即真实同步
- 引擎侧：OfflineQueue 既有查询/触发面复用，缺则补只读

### 3. 冲突提示与处理
- tauri：`cmd_conflict_list`（artifact 列表）/ `cmd_conflict_resolve`（手动选择——conflict.rs 既有语义冲突手动选择面）
- 前端：冲突列表 + 解决交互（采纳本地/远端/分支模式——conflict.rs 既有枚举）
- 引擎侧：conflict artifact 查询/解决面复用
