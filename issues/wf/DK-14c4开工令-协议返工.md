# DK-14c.4 开工令 · 数据面协议返工（string→原生类型）

**派发**: Alpha 2026-10-14 14:40 ｜ **Assignee**: Bravo ｜ **Estimate**: 2-3h ｜ **依据**: `issues/wf/alpha-DK14c3-验收注记.md`（实验证伪受阻论证+返工蓝本在档）｜ **依赖**: 14c.3（b8a0449 有条件收卡）

## 背景一句话

14c.3 的 string 协议化基于错误受阻论证（bindgen trait 路径下 option/list/result 原生支持，Alpha 已实验实证：host+guest 全链编译 EXIT=0，guest 仅 1.22s）——返工为设计稿原令形态。

## 任务

### 1. WIT（0.2.0 内）

```
read-doc:  func(token: borrow<capability-token>, doc-id: string) -> option<string>;
write-doc: func(token: borrow<capability-token>, doc-id: string, data: string) -> result<_, string>;
query-docs: func(token: borrow<capability-token>, pattern: string) -> list<string>;
```

### 2. 宿主（bindgen Host impl 内改返回类型，挂载/require/审计/guard 不动）

- read_doc: `-> wasmtime::Result<Option<String>>`（`docs.get().cloned()` 直返）
- write_doc: `-> wasmtime::Result<Result<(), String>>`（外层 wasmtime trap 语义/内层协议 err——guard 超限与写失败走内层 Err）
- query_docs: `-> wasmtime::Result<Vec<String>>`（键集 Vec 直返）
- 审计不变（write 逐条含 size / read+query 首调 / 越权 data-denied）

### 3. guest（hello lib.rs 适配，改法已实证）

- read 返回 Option：`is_none()` 判缺（实验已验证 bindgen 生成形态）
- write 返回 Result：`is_err()` 判败
- query 返回 Vec：`.len()`/迭代替代 lines().count()

### 4. e2e 断言升级+回归例

- 哨兵值断言改类型断言（None/Err/Vec.len()）
- **新增回归例**：空内容文档（write "" → read Some("")——消除空串歧义）；含换行 doc_id（write "a\nb" → query 检索→键集类型保证无解析歧义）
