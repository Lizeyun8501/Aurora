## 15a · capability 串→类型化（fail-closed 校验，XS）

### 设计

1. **fail-closed**：manifest 解析遇未知 capability 串→**拒绝加载**（Error 带非法串名与位置），禁止静默忽略（fail-open 是能力面漏洞——未知权限静默丢弃=guest 预期能力缺失行为不可预测）
2. **双端类型对齐**：Rust `Permission/Capability` ↔ `shared/types/src/plugin.ts` TS `Capability` 枚举——新增对齐测试（serde 序列化↔TS 字面量互证，防漂移）；TS 侧如有缺失变体补齐
3. **诊断**：拒绝信息含非法串+合法清单
4. **范围停手**：不做 per-method 细粒度（与 C-ns 同期 L1）、不改已发 manifest 兼容性（合法串全集不变）

## 15b · 用户可见输出（受控通道，S）

**定性**（14e1 收紧的 功能化——不回退红线）：**不恢复 stdout 继承**（插件=不可信代码，读宿主 stdin/写宿主 stdout 超必要面）。改为**能力化的受控输出通道**。

### 设计

1. **Capability::UserOutput 新变体**：WIT `print: func(token: borrow<capability-token>, text: string) -> result<_, string>`（形态复用 14c.4 原生类型裁决；require(UserOutput)+越权 denied 审计——14c.3 差异化审计模式复用：print 逐条审计？——**否**，print 可能高频——首调+越权审计，内容经 tracing debug 留痕）
2. **宿主缓冲**：per-plugin 环形缓冲（上限 64 KiB/插件，FIFO 淘汰）——`WasmStoreCtx` 加字段
3. **消费 API**：host-invoked `pull_output(plugin_id) -> Vec<String>`（宿主/桌面拉取；不设推送——15s 轮询现状兼容，T6 实时推送后可挂 event）
4. **与 log 分界**（文档化）：log=诊断流（stderr/tracing，开发者向）；UserOutput=用户可见内容（缓冲可拉取，产品向）
5. **hello 演示**：handle-event 里 print 一行（manifest 补 UserOutput）+e2e（granted 打印可拉取/越权拒/缓冲淘汰 64KiB）

### DoD

- [ ] WIT print+产物 import 面实证；require+首调/越权审计
- [ ] 缓冲 64KiB 淘汰测试+pull_output 拉取测试+e2e 三例
- [ ] log/UserOutput 分界文档化；CI 全绿
