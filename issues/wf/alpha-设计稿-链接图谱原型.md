# [Alpha 设计稿] DK-链接图谱原型（2.1 尾巴之二——挂起池大活拆小）

> 出稿: Alpha ｜ 日期: 2026-10-17 ｜ 定性: 原型（prototype——视觉/交互定版后再谈产品化）

## v1 范围裁定

**全库图谱 + 简化力导向静态布局**：

1. **数据层**（desktop commands，core 不动）：
   - `cmd_links_graph() -> {nodes: [{id, title, degree}], edges: [{src_id, dst_title}]}`——`links:out:*` 扫描（S1 键域）+ unseal 标题补全（backlinks_of 同款通路）；**锁定篇照常参与**（title=None 兜底显示短 id——反链面板先例）；**trash 排除**
   - 边语义：src 笔记 out 集含目标标题——**dst 按标题反查 id**（无对应笔记=悬挂节点虚显示，S1 惰性一致）
2. **布局 v1**：**静态预计算力导向**（spring-embedder 简版：斥力+弹簧引力，~120 次迭代预计算，无动画）——SVG 渲染；初始位置圆周种子
3. **护栏**：节点上限 **80**（超出按 degree 取 Top80+提示文案「已裁剪，仅显示连接最多的 80 篇」）
4. **交互 v1**：节点点击→跳转笔记（onSelect 复用）；hover 高亮邻接边+邻居；**缩放/拖拽/动画延后**（诚实边界）
5. **挂载位**：EditorPane 底部面板位与反链并列——**Tab 切换「反链 | 图谱」**（布局最省——3.1 右侧常驻面板另批）

## 呈现纪律

- 节点=圆+标题短标签（超长截断）；边=细线（悬挂边虚线）；空态（无边）占位
- 插件输出同款不可信纪律：标题文本 SVG text 原样（无 HTML interpret）

## 停手条款

- 不做实时动画/物理模拟交互；不做子图过滤/搜索定位；不做图谱导出
- 移动端不适配（桌面优先）
